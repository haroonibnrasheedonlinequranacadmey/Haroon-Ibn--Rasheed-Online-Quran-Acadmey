MISHKAT AL-BAYAN — UPDATED PACKAGE NOTES

Original supplied project files and data are retained. Existing Quran source dataset, current translation/Tafseer integration, learner app, PDF, audio logic, bookmarks, PWA and offline worker remain in place.

Changes in this update:
- Header controls remain on the right and academy/project brand remains on the left.
- Added Arabic / Translation / Word By Word settings tabs.
- Added Arabic font-style selector, size controls, line-count preference, translation display/language/size/layout controls, word-by-word toggle, theme selector and reciter status.
- Default first-run Arabic size is Normal (30px), and default reader font-style preference is Uthmani text style with system fallback.
- Added local My Quran page with saved-ayah list, recent position and persistent notes.
- Added Reading Goals page with a persistent daily ayah target and last-position display.
- Added Light, Dark, Sepia and Auto theme styling for key reader surfaces.
- Updated cache version and asset query versions.

IMPORTANT DATA / FEATURE LIMITATIONS — NOT CLAIMED AS COMPLETE:
1. The supplied font file is KFGQPC KSA Regular, not verified Uthmanic Script HAFS; it is not relabelled as an authentic Uthmani font. The selector uses browser/system fallback stacks. IndoPak and Tajweed font files were not supplied and are not bundled.
2. The only Urdu translation edition already configured in the source integration is Fateh Muhammad Jalandhri. The other requested Urdu translator/tafsir works were not fabricated or added without verified source datasets/edition IDs and redistribution rights. Fi Zilal, Bayan-ul-Quran and Tafheem-ul-Quran are tafsir works, not interchangeable translation editions.
3. Word-by-word meanings continue to load from the existing Quran.com QDC online integration; offline word data is not bundled.
4. The reader's existing audio endpoint remains Mishary Rashid Alafasy. Additional reciters are not configured.
5. The existing source did not contain complete revelation-order metadata, full Arabic Surah names, or a complete page/juz index as local data. Page/Juz navigation continues to depend on the existing AlQuran Cloud service.
6. Annual plan completion analytics, multi-position reading bookmarks, collections, full lesson/reflection/answers/hadith/related-content database, and per-ayah study tabs have not been fully implemented. The Reading Goals page explicitly avoids claiming automatic completion tracking.
7. The new My Quran notes and goals use browser localStorage and do not sync between devices.
8. The supplied ZIP does not contain ../assets/hr-logo-round.png; the original academy logo reference is retained but the image itself is expected from the parent academy site.
9. Interactive testing on a physical Android phone, iPhone and laptop was not possible in this environment. External services require internet access.

Validation performed for this package: JavaScript syntax checks, manifest JSON validation, Quran data structure/count checks, archive integrity check. These are static checks, not a substitute for real-device/browser testing.
