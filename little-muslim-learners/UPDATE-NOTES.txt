MISHKAT AL-BAYAN — UPDATE NOTES

Changes in this update:
- Header now uses Menu and Settings controls; Learner Profile and Urdu controls are no longer shown in the header. Legacy learner/profile logic and hidden DOM hooks remain intact.
- Main navigation opens from the hamburger menu.
- Quran Text opens with a searchable list of all 114 Surahs. Selecting a Surah closes the list.
- Surah title area is a compact collapsible header.
- Top reader navigation includes Surah, Juz, Page and Ayah controls.
- Audio dock remains at the bottom of the Quran reader.
- Bismillah is displayed separately at the start of Surahs other than Al-Fatiha and At-Tawbah. A prefixed Bismillah is removed from the displayed first Ayah only; the original bundled quran-data.js remains unchanged. An-Naml 27:30 is not altered.
- Existing Quran data, Tafseer, translations, With Meaning/other sections, PDF and other assets are retained.

Checks performed:
- JavaScript syntax checks passed for app.js, quran-library.js, quran-data.js, quran-validation.js and sw.js.
- manifest.webmanifest JSON validation passed.
- HTML parser check passed; no duplicate element IDs found.
- Bundled Quran dataset count verified: 114 Surahs and 6,236 Ayat.
- Bismillah rule checks passed for Al-Fatiha, Al-Baqarah, An-Nisa, At-Tawbah and An-Naml 27:30.

Limitations:
- Full interactive browser testing could not be completed in this execution environment because Chromium navigation was blocked by the environment.
- External translation, Tafseer, recitation and Mushaf/PDF network resources were not live-verified here and require internet access.
