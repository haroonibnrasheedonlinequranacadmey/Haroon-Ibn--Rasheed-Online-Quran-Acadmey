MISHKAT AL-BAYAN — UPDATE NOTES

Changes in this package:
- Added an individual end-of-ayah marker (۝ plus that verse’s Arabic-Indic number) to each of the 6,236 rendered ayat. The bundled Quran source text remains unchanged.
- Corrected the marker position so it is appended after the Arabic text of its own ayah, not before the ayah or attached to the next ayah.
- Moved Menu and Settings controls to the left and the academy brand/logo to the right in the top header.
- Kept the 114-Surah picker in its own independently scrollable area.
- Removed the fixed bottom audio control dock and floating Tafseer tutorial button/modal as marked in the supplied screenshots. Per-ayah Listen and Play Surah actions remain in the reader.
- Preserved the supplied Quran text, translations/Tafseer code, bookmarks, search, learner data, PDF and other existing learning sections.

Validation performed:
- Verified bundled source contains 114 Surahs and 6,236 non-empty ayat.
- Verified the source Quran text contains no pre-existing end-of-ayah glyphs, so each rendered ayah receives exactly one separate marker.
- JavaScript syntax and JSON/manifest checks are run during packaging.

Font package update:
- Added the user-supplied KFGQPC-KSA-Regular.ttf at assets/fonts/KFGQPC-KSA-Regular.ttf and registered it with @font-face.
- The supplied font metadata identifies it as KFGQPC KSA Regular, not KFGQPC Uthmanic Script HAFS. It has limited Quranic glyph coverage; unsupported Quranic marks and symbols use CSS fallback fonts. The exact requested Uthmanic Script HAFS font is still not included.

Testing limitation:
