Install

  • Windows: right-click the font file → Install (or drag it into Settings → Personalization → Fonts).
  • macOS: double-click the font → Install Font (Font Book).
  • Linux: copy to ~/.local/share/fonts and run fc-cache -f.

@font-face {

  font-display: swap;
