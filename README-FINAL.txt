HAROON IBN RASHEED ONLINE QURAN ACADEMY — FINAL PACKAGE

1. Upload the contents of this folder to the root of your GitHub Pages repository.
2. In Supabase SQL Editor run: supabase/schema.sql (whole file, once).
3. Confirm Authentication URL Configuration: your GitHub Pages URL and /admin/reset-password.html.
4. The public registration creates Student accounts automatically.
5. Admin promotes a registered account to Teacher from Admin > Portal Users, then links the UUID in Admin > Teachers.
6. Admin links Student account UUID in Admin > Students.
7. Create schedules/classes using the account UUIDs.
8. Do not put a Supabase service-role key in the website. The included anon/publishable key is the only browser key.

Existing public WhatsApp, message/chat, admission and payment buttons are retained.
